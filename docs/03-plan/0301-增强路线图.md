# 0301 增强路线图

> 状态：计划文档。每项落地后把条目移入对应 01-tech 文档并在此标记 ✅（含版本）。

基线：graph-memory v1.6.0-beta.17 功能已全量移植（差异见 `docs/01-tech/0104`）。以下按优先级排列本项目自身的增强。

## P1 宿主集成深化

- [ ] **slot 客户端面板（Web UI）**：按 `dsh-kylin-automation` 模式增加 `src/client/`，经 `ctx.slots.inject('sidebar.panellist')` + `register('main')` 注册记忆面板；Host 侧挂 webServer RPC（`RpcResult<T>` 信封），面板展示：轮次记忆列表、SPO 导航图、抽取队列/隔离状态、token 节省统计。package.json 增补 `dsh.client`/`qilin.client` 块。
- [ ] **`km_forget` 工具**：按 session/主题显式删除轮次记忆及其 SPO/向量（当前只能等 retention GC 或手工动库）。删除必须连带：导航词项引用计数、turn vectors、来源关系，事务内完成。
- [ ] **抽取退避调度启用**：`extraction_next_retry_at` 列已存在但从未启用（上游债务）。给可重试错误（路由/供应商）配指数退避 + `km_status` 显示下次重试时间。

## P2 记忆质量

- [ ] **矛盾处理**：同一实体新轮次与旧记忆冲突时（benchmark 场景就是"改已确立的事实"），在 SPO 上标 `SUPERSEDES` 边而不是只靠时间序。
- [ ] **召回评测**：移植上游 `benchmarks/` 的 20 轮场景，建立本项目自己的回归基线（上下文接管率 + 轮次通过率），增强后可对比。
- [ ] **多主题宽查询**：召回前做轻量查询拆分（本地词项切分，不加 LLM 调用），多路种子各自 PPR 后融合。

## P3 规模与工程

- [ ] **向量检索 ANN**：余弦暴力扫描在万级 turn memories 后成为热点；评估 sqlite-vec 或分块暴力+提前终止。
- [ ] **N+1 查询收敛**：`getTurnMemoriesByIds` / `toTurnMemory` / `getNavigationTriplesForMemories` 批量化。
- [ ] **`test/helpers.ts` 去 drift**：改为直接调用 `migrate()` 建库（上游债务，测试基建）。
- [ ] **旧概念图退役评估**：`km_record` 写入的 TASK/SKILL/EVENT 概念图与导航图并存的边界梳理，生产路径已无调用方的旧 API 清理。
