基线：graph-memory v1.6.0-beta.17 功能已全量移植（差异见 `docs/01-tech/0104`）。以下按优先级排列本项目自身的增强。

## P1 宿主集成深化

- [x] **slot 客户端面板（Web UI）** ✅ v0.1.0：`sidebar.panellist` + `main` 双 slot，`/dsh-kylin-memory` RPC 通道（overview/memories/forget），webServer/connection 动态注入保持可选面语义。见 docs/01-tech/0105。
- [x] **`km_forget` 工具** ✅ v0.1.0：按 session/单条删除轮次记忆，事务内级联来源/向量/SPO，孤儿导航词项回收（共享词项存活），共享引用的原始消息保留；面板与工具共用同一存储原语。
- [ ] **抽取退避调度**（设计决策待定）：`extraction_next_retry_at` 列已存在但从未启用——上游**有意**不自动重试（路由/供应商错误停住，避免反复打供应商），自动退避与该哲学有张力。若启用：仅对可重试错误配指数退避 + `km_status` 显示下次重试时间；否则考虑在后续迁移里删掉该列。

## P2 记忆质量

- [ ] **召回评测**：移植上游 `benchmarks/` 的 20 轮场景，建立本项目自己的回归基线（上下文接管率 + 轮次通过率），增强后可对比。
- [ ] **多主题宽查询**：召回前做轻量查询拆分（本地词项切分，不加 LLM 调用），多路种子各自 PPR 后融合。
