## 相对上游的增强（本项目新增）

1. **环境变量回退收进适配器**（`withEnvironmentDefaults()`）：上游在 cordis.patch.yml 用 `!!js` 表达式读 env，依赖宿主求值器且 QiLin 不保证支持。本项目 patch 保持纯静态 YAML，env 解析可单测、双宿主一致。
2. **数据目录双宿主解析**：`KYLIN_MEMORY_DATA_DIR → $DSH_HOME → $QILIN_HOME → ~/.dsh`。
3. **`KYLIN_MEMORY_SEMANTIC_SCORE_THRESHOLD`** 环境变量覆盖余弦门槛（上游只能改 patch config）。
4. **`km_forget` 遗忘工具与存储原语**（`forgetTurnMemories`）：上游没有显式删除路径；本项目按会话/单条事务删除，级联来源/向量/SPO，孤儿导航词项回收、共享词项与被共享消息保留。
5. **Web 记忆面板与 RPC 通道**：上游的 Web 面板属于独立的 DSH Pro 产品（本项目裁掉）；本项目按家规自建 `sidebar.panellist`+`main` slot 面板与 `/dsh-kylin-memory` RPC 通道，`webServer`/`connection` 走动态子世界注入保持可选面（见 docs/01-tech/0105）。
6. **家规工程面**：esbuild 单入口自包含双 bundle（上游是 tsc 多产物 + 生成物 dist）、`scripts/smoke-plugin.mjs` 发布面契约检查、`dsh`/`qilin` 双 manifest 块、peer 全 `*` 策略。
7. **生命周期包（v0.1.1）**：事实失效 m17、workspace 作用域 m19、轮次记忆 trigram FTS5 m18、别名归一层 m20、删除审计 m21、FTS5 主路线 + LIKE 兜底、`freshnessHalfLifeDays` 衰减、`assistantTools` 默认 `search`、embedding 重探针 + 启动增量补嵌、CI 与基准入仓；v0.1.2 复查修复 supersede 三元组成对匹配与 retention 轮次证据引用检查，补齐 lastProbeAt / RPC workspace 分组与 forget 过滤 / `KYLIN_MEMORY_SEMANTIC_SCORE_THRESHOLD` env（详见 0302 补遗）。

## 已知与上游共有的债务（移植时保留）

系统性的缺陷登记与业界对标见 `docs/02-design/0201-缺陷分析与业界对标.md`（编号 A1..D4/B1..B5，修复排期见 `docs/03-plan/0302`）。与上游共有的代表性条目：

- 新旧两代数据模型共存：旧概念图（`km_nodes`/`km_edges`）与新轮次记忆并行，旧图 PPR/社区代表等 API 在生产召回路径已无调用方（仅 `km_record` 写入与兜底召回使用）；
- 向量检索为全表暴力余弦扫描，Top-K 小时无碍，规模大需 ANN；
- ~~`test/helpers.ts` 手工复刻 schema，与 `migrate()` 有漂移风险~~ ✅ v0.1.1 已改用真实 `migrate()` 建库；
- 抽取失败重试的 `next_retry_at` 退避列已建但未启用（重试靠 `km_retry_extraction` 显式触发）。
