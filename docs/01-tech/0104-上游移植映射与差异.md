## 相对上游的增强（本项目新增）

1. **环境变量回退收进适配器**（`withEnvironmentDefaults()`）：上游在 cordis.patch.yml 用 `!!js` 表达式读 env，依赖宿主求值器且 QiLin 不保证支持。本项目 patch 保持纯静态 YAML，env 解析可单测、双宿主一致。
2. **数据目录双宿主解析**：`KYLIN_MEMORY_DATA_DIR → $DSH_HOME → $QILIN_HOME → ~/.dsh`。
3. **`KYLIN_MEMORY_SEMANTIC_SCORE_THRESHOLD`** 环境变量覆盖余弦门槛（上游只能改 patch config）。
4. **家规工程面**：esbuild 单入口自包含 bundle（上游是 tsc 多产物 + 生成物 dist）、`scripts/smoke-plugin.mjs` 发布面契约检查、`dsh`/`qilin` 双 manifest 块、peer 全 `*` 策略。

## 已知与上游共有的债务（移植时保留，见路线图）

- 新旧两代数据模型共存：旧概念图（`km_nodes`/`km_edges`）与新轮次记忆并行，旧图 PPR/社区代表等 API 在生产召回路径已无调用方（仅 `km_record` 写入与兜底召回使用）；
- 向量检索为全表暴力余弦扫描，Top-K 小时无碍，规模大需 ANN；
- `test/helpers.ts` 手工复刻 schema，与 `migrate()` 有漂移风险；
- 抽取失败重试的 `next_retry_at` 退避列已建但未启用（重试靠 `km_retry_extraction` 显式触发）。

处置计划见 `docs/03-plan/0301-增强路线图.md`。

## 与上游的同步策略

上游仍在活跃开发（兼容性修复线）。若上游发布新的关键修复（尤其 `src/format/dsh-*.ts` 表面协议与 `src/store/db.ts` 迁移），评估 cherry-pick：移植映射以本文为准，重命名规则见上表，迁移必须追加在 `steps` 数组末尾、不改写已发布编号。
