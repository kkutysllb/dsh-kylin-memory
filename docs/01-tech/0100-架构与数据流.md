# 0100 架构与数据流

> 状态：与 `src/` 当前实现同步。改了代码里的事件名、表名或流程，请同步更新本文。

Kylin Memory 是 DSH（DeepSeek Harness）与 QiLin/Kylin 的知识图谱记忆插件。核心思想：**限制上下文，让记忆继续生长**——接管发给模型的历史表面，保留最近 N 轮原生问答，把更早的历史变成可检索的图记忆，需要时自动召回并带回精确原文。

## 两层记忆

| 层 | 内容 | 用途 | 能否作为最终证据 |
|---|---|---|---|
| 导航层 | 每轮一句自包含摘要 + outcome + SPO 三元组 + 摘要向量 + LPA 社区标签 | 快速定位相关轮次 | 否，只是索引 |
| 事实层 | 原始用户问题 + 最终可见回答（`km_messages`，带溯源关系） | 召回时注入提示词 | 是 |

"最近 N 轮"（默认 5）是宿主的工作上下文窗口，不是第三层记忆。宿主的不可变事件日志完整保留；本插件只替换**模型可见表面**（model-visible surface），绝不删除事件。

以下内容永远不会进入轮次记忆：reasoning/thinking、中间 assistant 草稿、tool call 参数与结果、UI 截断预览、插件自己生成的召回快照。

## 写入数据流

```text
宿主 turn/end
  │
  ├─ 轮次投影：从不可变事件日志选出首个真实 user + 最后一个可见 assistant
  │
  ├─ 后台串行队列（每 session 一条 Promise 链）
  │      └─ 每个完整轮次恰好 1 次抽取 LLM 调用
  │           submit_result({ summary, outcome, triples[] })
  │
  ├─ TypeBox 运行时校验（fail-closed）
  │      ├─ 合法：原子写入 摘要 + 来源关系 + SPO（单事务）
  │      └─ 非法：隔离该轮；不猜测、不修补、不污染图谱
  │
  ├─ 事实失效：同 (subject, predicate) 新值标记旧 triple（superseded_by，零 LLM）
  ├─ 异步写摘要向量（可选 embedding；失败静默降级 FTS5）
  └─ 本地 LPA 更新导航社区（零 LLM 调用）
```

## 召回数据流

```text
下一轮 user query（agent/pre-step，仅 step===1）
  │
  ├─ 摘要向量 Top-K；词法路线 trigram FTS5（短查询回退 LIKE）
  ├─ recallScope=same-workspace 时按 workspace 过滤三条路线
  ├─ 查询词项 / 摘要命中 → 导航种子（字面匹配优先，防止二次调模型）
  ├─ 种子所在社区缩小候选 → 查询时 Personalized PageRank
  ├─ RRF（reciprocal rank fusion）融合摘要路线与图路线
  ├─ 剔除已被同批召回的新记忆显式失效的旧记忆（km_forget 删除失效者可恢复）
  └─ 命中 turn memory → 回溯原始 Q/A，插入当前用户消息之前
```

## 上下文接管

- `src/format/dsh-compaction.ts`：滚动保留最近 `freshTurnCount` 个真实用户轮；更旧的表面前缀替换为一个**常量大小**的归档标记（旧标记下次一并折叠，不累积）。全程零 LLM 调用。
- `src/format/dsh-turn-projection.ts`：完成轮次内部的 reasoning/工具轨迹替换为常量标记，只保留问答两端点。通过宿主公开的 `surfaceOp: { op: "replace", startSeq, endSeq }` 实现，并用 `tokenMeter.measure()` 记录影子价格让 token 统计精确扣减。
- 写入走 `session.append("compaction/prune", ...)`，宿主不可变日志不受影响。

## 模块地图与依赖方向

```text
src/types.ts            全链路类型合同（KmNode/KmTurnMemory/ExtractionResult…）
src/store/db.ts         node:sqlite + 16 个顺序迁移 + FTS5 + WAL/busy_timeout
src/store/store.ts      存储原语（幂等写入、向量暴力扫描、导航词项/三元组）
src/store/retention.ts  持久层保留策略（all/referenced/recent，只删无引用行）
src/store/…             迁移 m17 事实失效 / m18 轮次 FTS5(trigram) / m19 workspace 作用域
src/extractor/          抽取合同（TypeBox schema + submit_result）与提示词
src/engine/embed.ts     OpenAI 兼容 embedding（含 MiniMax 特判，失败→FTS5）
src/engine/dsh-extraction-route.ts  抽取路由与 reasoning effort 协商
src/graph/pagerank.ts   自研 PPR（按连接 WeakMap 缓存，写入后显式失效）
src/graph/community.ts  自研确定性 LPA（排序遍历+字典序平票）
src/recaller/recall.ts  双路召回 + RRF + 来源回溯
src/format/assemble.ts  组装 <episodic_context>（摘要导航 + 精确 Q/A 证据）
src/format/dsh-*.ts     宿主表面投影/压缩/召回插入（DSH 与 QiLin 共用）
src/index.ts            宿主适配入口（name/inject/apply + km_* 工具 + RPC 接线）
src/rpc.ts              RPC 管理通道（/dsh-kylin-memory，headless API，动态注入；无 UI）
```

依赖方向强制为：`types → db/store → extractor + graph → recaller → assemble`，宿主适配（`src/index.ts`）只能从上往下引用，`store/graph/recaller` 不反向读取宿主会话。

## 工具面

| 工具 | 用途 |
|---|---|
| km_status | 存储、抽取、召回、向量与保留策略全景 |
| km_search | 显式搜索图记忆（自动召回不依赖工具调用） |
| km_record | 确定性写入 TASK/SKILL/EVENT |
| km_stats | 图谱与保留策略回执 |
| km_maintain | 执行一次有界维护（PageRank/社区/保留 GC） |
| km_retry_extraction | 显式重试待处理或隔离的抽取任务 |
| km_forget | 按会话或单条删除轮次记忆，级联清理来源/向量/SPO，孤儿导航词项回收；支持 dryRun |

默认 `assistantTools: "search"`：agent 可显式调用 km_search 自主查记忆（"none" 恢复完全被动，"all" 开放管理工具）。

`assistantTools` 默认 `none`（工具仅供内部/管理使用）；设为 `search` 只注册 km_search，`all` 注册全部管理工具。

## 失败语义

- 结构合同失败 → 隔离该轮（错误信息不含模型输出原文）；
- 路由/供应商错误 → 保持 pending，修正配置后 `km_retry_extraction` 恢复；
- 抽取/embedding/维护失败 → 一律 fail-open，绝不阻塞前台对话；
- 压缩失败 → fail-open，当轮历史照常发送。
