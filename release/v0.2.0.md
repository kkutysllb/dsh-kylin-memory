# v0.2.0

## 版本信息

- 发布日期：2026-10-02
- 基线：v0.1.0（0d07a6c）
- 主题：记忆生命周期补全（docs/03-plan/0302 的 M1/M3/M2/M5/M6.1/M6.3）

## 新增

- **事实失效（A1）**：同 (subject, predicate) 新值到达时旧 triple 标记失效（m17 `superseded_by` / `superseded_count`），召回剔除已失效记忆（失效者未被召回时旧记忆保留）；`km_forget` 删除失效者时自动恢复。零 LLM 调用，保守字面匹配（谓词表述差异会漏判，已在文档标注 v1 边界）。
- **记忆作用域（D1）**：m19 `workspace_id` 列（旧数据回填 `default`）+ `recallScope: "all" | "same-workspace"` 配置（默认 `all` 行为不变）；词法/向量/图三条路线与 RPC 列表均支持过滤。
- **轮次记忆 FTS5（B1）**：m18 trigram 分词（CJK 子串可用），词法主路线升级，短查询/不可用回退全短语 LIKE。
- **导航新鲜度衰减（B5）**：`freshnessHalfLifeDays`（默认 0=关），PPR 记忆分数按 exp 半衰期衰减。
- **基准移植（C6）**：上游 20 轮场景入仓 `benchmarks/dsh-context-takeover/`（v72/v73 为上游历史），本仓基线待首次运行。
- **CI（C3）**：GitHub Actions push/PR 跑 check + smoke + verify:package。

## 变更

- **`assistantTools` 默认值 `none` → `search`**：agent 现在默认可显式调用 `km_search`（Letta 式自主查询）；自动召回仍是主路径，`"none"` 恢复完全被动。
- `test/helpers.ts` 改用真实 `migrate()` 建库（C4，手工 schema 漂移曾在 m17 当场兑现为 bug）。

## 删除

- 无。

## 兼容性

- Node.js ≥ 22.13.0；DSH 0.1.7+ / QiLin 3.0+ 不变。
