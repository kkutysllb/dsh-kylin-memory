# v0.2.0

## 版本信息

- 发布日期：2026-10-06
- 基线：v0.1.3
- 主题：适配麒麟引擎新版本（QiLin 3.0.11）——插件详情页设置卡改按 QiLin 契约渲染（breaking：DSH 时代 settings 原语依赖移除）

## 新增

- `scripts/smoke-client.mjs`（`npm run smoke:client`）：用模块表等价桩按 shell 的方式加载 `lib/client.js`、执行 `apply`，断言注册 keyed 槽位 `plugins.bundle.config:dsh-kylin-memory:kylinMemory.settings` 并注册字典命名空间；同时断言入口不再注入退休的 `configForms` 服务。
- smoke 第 4 节改按新契约正向断言：client 注入面收窄为 `slots` / `locale`（`configForms` 零残留）、设置卡消费页面契约 `form.state` / `form.mutate`、DSH 时代 settings 原语零残留；manifest `client.inject` 检查改按引擎 doctor 的 `client-inject` 规则（依赖边 informational，dsh-compat 可映射名即过）。

## 变更

- **客户端设置卡渲染契约**（`src/client/` → `lib/client.js`）：由 DSH 时代 settings 原语（`SettingsForm` / `SettingsFormModel` / `SettingsValueField` / `settingsNumberField`，QiLin 3.0.11 的 `@qilin/client-ui-primitives` 已不含这些符号）改为 QiLin 的 `plugins.bundle.config` 槽契约 `PluginConfigViewProps`：
  - 页面自带 form 并交给卡片 `form.state`（`status` / `value` / `user` / `revision` / `writable`）与 `form.mutate`；
  - 卡片本地暂存编辑，一次保存把全部改动以 `{ op:'set'|'unset', path:[field], value }` 批量提交，并以读到的 `revision` 为栅栏；离开页面丢弃未保存编辑；
  - 字段是否被覆盖以 `state.user` 里**是否存在该键**判定（值相同也可能是覆盖），恢复默认走 `{ op:'unset' }`；
  - 渲染改用 QiLin 原语 `Input` / `Button`（经 shell 模块表 DSH 别名解析，react 仍不打包）；
  - `summary` 座位留空（页面自绘标题与一句话简介）。
- client 入口 `inject` 由 `["slots", "locale", "configForms"]` 收窄为 `["slots", "locale"]`——不再注入退休的 `configForms` 服务，设置页面的命名空间状态由详情页自己供给。
- 用户可见的表单语义与 v0.1.3 一致：四个字段（`freshTurnCount` / `maintenanceInterval` / `recallMaxNodes` / `semanticScoreThreshold`）、已覆盖标记、恢复默认、一次保存；宿主侧 `Config` schema 与 volatile live-edit 机制不变。

## 修复

- **QiLin 3.0.11 上客户端插件整体加载失败**：v0.1.3 的客户端半边按 DSH 时代 API 写，浏览器报 `(0 , import_…settingsNumberField) is not a function`，整个客户端插件加载失败（宿主半边不受影响，记忆功能正常）。本版改按 QiLin 契约渲染后消除。

## 删除

- 对 DSH 时代 settings 原语的依赖：`SettingsForm` / `SettingsFormModel` / `SettingsValueField` / `settingsNumberField`（产物内零命中）。
- `configForms` 服务注入与命名空间绑定（页面自带 form，卡片只消费 `form.state` / `form.mutate`）。

## 兼容性

- **BREAKING（仅客户端半边）**：设置卡要求宿主详情页提供 `plugins.bundle.config` 表单契约（`PluginConfigViewProps`，QiLin 3.0.11 确认提供）；更旧引擎上客户端插件可能加载失败或设置卡不出现。宿主半边（记忆引擎、km_* 工具、RPC 通道）无版本要求变化。
- manifest（`dsh` / `qilin` 的 `client.inject` 依赖边）不变：引擎侧为 informational 依赖边，`@deepseek-ai/dsh-*` 名经 dsh-compat 前缀规则映射后均可解析，doctor 规则通过。
- 数据与配置完全兼容：不新增迁移（仍 m1–m21）、不改配置键、用户覆盖层与 bundle patch 分层语义不变；`PluginConfig` / schema 导出面不变。

- `npm run smoke:client`：模块表等价桩加载产物 → `apply` → 注册 `plugins.bundle.config:dsh-kylin-memory:kylinMemory.settings` + 字典命名空间，全链路走通。
- 本次行为变化不触及适配器与 manifest，按发版流程未强制双通道真实宿主安装冒烟；客户端契约对照 QiLin 3.0.11 引擎源码（`ui-plugin-manager` slot-contract、`dsh-compat` 别名表、doctor `client-inject` 规则）核验。
