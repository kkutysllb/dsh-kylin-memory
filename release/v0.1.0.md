# v0.1.0

## 版本信息

- 发布日期：2026-10-02
- 上游基线：adoresever/graph-memory v1.6.0-beta.17（MIT）
- 适配宿主：DSH 0.1.7+（Session V4）/ QiLin 3.0+

## 新增

- 知识图谱记忆引擎全量移植：轮次摘要 + SPO 导航 + 精确 Q/A 事实源的两层记忆；本地 LPA 社区与 Personalized PageRank；双路召回 RRF 融合。
- DSH / QiLin 双通道：同一份 bundle，`dsh` + `qilin` 双 manifest 块（含 client 交付面），纯静态 `cordis.patch.yml`。
- 适配器内环境变量回退（`KYLIN_MEMORY_*`）与数据目录双宿主解析（`KYLIN_MEMORY_DATA_DIR → $DSH_HOME → $QILIN_HOME → ~/.dsh`）。
- 7 个 `km_*` 工具：status / search / record / stats / maintain / retry_extraction / **forget**（新增：按会话或单条遗忘，事务级联清理，共享词项与被共享消息保留，支持 dryRun）。
- headless RPC 管理通道 `/dsh-kylin-memory`（overview / memories / forget）：`webServer`/`connection` 经动态子世界注入保持可选面语义，极简 profile 自动降级；供脚本与外部工具在宿主登录态下调用。
- 无 UI（产品定案）：不注册任何 Web client/slot，对齐上游纯 Agent 工具入口；决策记录见 docs/01-tech/0105。
- 家规工程面：esbuild 自包含 bundle（lib/ 入仓）、smoke 发布面契约、verify:package、release/ 发版流程、dsh-plugins 镜像同步、docs/ 编号文档体系。

## 变更

- 相对上游：表前缀 `gm_`→`km_`、工具前缀、表面标记、来源标识全部品牌重映射（见 docs/01-tech/0104）。
- 环境解析从上游的 patch `!!js` 表达式移入适配器（QiLin 兼容 + 可单测）。

## 删除

- 上游 OpenClaw 通道（`index.ts` 适配、`engine/llm.ts`、`llm-guard.ts` 及其测试）——本项目定位 DSH + Kylin 双通道。
- 上游实验性 `pro/`、`dsh-pro/`。

## 兼容性

- Node.js ≥ 22.13.0（内置 `node:sqlite`）。
- DSH 0.1.7+ / Session V4；QiLin 3.0+（插件管理页建议 3.0.2+）。
- 无 UI：本插件不注册任何侧边栏/面板入口，管理走 `km_*` 工具与 RPC 管理通道。
- 无既有数据库升级路径（首版；上游 16 个迁移完整移植，全新库一次到位）。
